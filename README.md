# Замер скорости скачивания

Консольный скрипт на Python: делает 10 последовательных GET-запросов к указанному адресу, каждый раз дочитывает ответ до конца и печатает:

- время каждого запроса;
- среднее время запроса;
- общий объём скачанных данных;
- скорость скачивания.

Сторонние зависимости не нужны, только стандартная библиотека.

## Требования

Python 3.8 или новее.

## Запуск

```bash
git clone <ссылка-на-репозиторий>
cd <папка-репозитория>
python speedtest.py "https://speed.cloudflare.com/__down?bytes=10000000"
```

На macOS и Linux вместо `python` может понадобиться `python3`.

### Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| `url` | обязательный | Адрес, который скачиваем (`http://` или `https://`) |
| `-n`, `--count` | `10` | Количество последовательных запросов |
| `-t`, `--timeout` | `30` | Таймаут одного запроса, в секундах |

```bash
python speedtest.py https://example.com/big-image.jpg -n 5 -t 60
```

### Пример вывода

```
Скачиваю https://speed.cloudflare.com/__down?bytes=10000000 — 10 раз(а) подряд...
  # 1:   10.000 MB за   0.823 с
  # 2:   10.000 MB за   0.440 с
  ...
  #10:   10.000 MB за   0.406 с

Запросов:              10
Скачано всего:         100.000 MB (100000000 байт)
Среднее время запроса: 0.472 с
Скорость скачивания:   169.39 Мбит/с (21.17 MB/s)
```

## Единицы измерения

- **Скорость: Мбит/с (мегабиты в секунду, 1 Мбит = 1 000 000 бит).** В этих единицах провайдеры и сервисы вроде Speedtest указывают скорость, так что результат легко сравнить с тарифом. В скобках та же скорость в **MB/s** (мегабайты в секунду, 1 MB = 1 000 000 байт).
- **Объём: MB (1 000 000 байт)**, в скобках точное число байт.
- **Время: секунды.**

Используются десятичные приставки (SI), а не двоичные (MiB = 1 048 576 байт).

## Как считается

- Время одного запроса: от отправки запроса до получения последнего байта тела ответа (`time.perf_counter`). Сюда входят DNS, TCP/TLS-рукопожатие и ожидание первого байта.
- Среднее время: сумма времени всех запросов, делённая на их количество.
- Скорость: `всего байт × 8 / суммарное время всех запросов`. Именно общий объём на общее время, а не среднее скоростей отдельных запросов, чтобы быстрые короткие запросы не искажали результат.
- Чтобы CDN не отдавал закэшированный ответ, отправляются заголовки `Cache-Control: no-cache` и `Pragma: no-cache`.
- Если хотя бы один запрос завершается ошибкой (HTTP 4xx/5xx, сеть, таймаут), скрипт выводит причину и выходит с кодом `1`.

## Тесты

Тесты поднимают локальный HTTP-сервер, поэтому интернет для них не нужен:

```bash
python -m unittest -v
```

## Замечание по выбору адреса

Некоторые сайты ограничивают частоту запросов. Например, `upload.wikimedia.org` на серии запросов отвечает `429 Too Many Requests`. Для замеров удобно использовать специальные тестовые файлы, например `https://speed.cloudflare.com/__down?bytes=10000000` (10 MB).
